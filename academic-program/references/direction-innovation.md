# 研究方向与创新复盘

仅在续接长期项目、阶段转换、出现实质性新证据、评估研究方向或提炼创新候选时读取。普通代码修改和单次实验执行不必加载。

## 研究罗盘

优先复用 `PROJECT.md` 或等价状态入口中的现有信息。需要长期维护且没有等价记录时，补充最小研究罗盘：

- 核心科学问题：项目最终要回答什么问题。
- 目标成果或目标主张：希望形成的论文贡献、系统能力或验证结论。
- 当前核心假设：现阶段最需要被证实或推翻的判断。
- 范围边界：哪些问题、输出或数据不属于当前主线。
- 下一项决定性验证：最能降低核心不确定性的下一步。

未知项标明待确认，不用猜测填满。罗盘仅在目标、假设、边界或决定性验证实质变化时更新。

## 方向状态

| 状态 | 判定含义 | 默认动作 |
| --- | --- | --- |
| `ALIGNED` | 当前工作直接降低核心问题的不确定性或形成目标证据 | 继续，并指明它推进了哪项主张或验证。 |
| `SUPPORTING` | 不直接形成贡献，但属于必要工具、数据、基线或可靠性工作 | 继续到足够支持主线为止，避免无限扩张。 |
| `EXPLORATORY` | 可能有价值，但与核心问题的联系尚未证实 | 给出低成本判别实验或时间边界，不自动升级为主线。 |
| `DRIFT_RISK` | 持续投入却不再降低核心不确定性，或输出逐渐偏离目标成果 | 说明偏离点和证据，建议收敛、暂存或返回主线。 |
| `PIVOT_CANDIDATE` | 原假设被关键证据削弱，或旁支出现更强且可验证的贡献 | 比较继续与转向的证据成本，提出最小决策实验。 |

方向检查只使用当前目标、近期工作和关键证据。不要为了复盘默认读取整个仓库、全部历史实验或所有文献。方向状态是决策提示，不代替实验有效性状态。

发现偏离时，用简短说明回答三个问题：当前工作与核心问题的关系是什么；哪些证据支持该判断；最小纠偏动作是什么。安全且有价值的工作可以继续；只有涉及核心目标、论文主张、显著成本、外部影响或授权变化时才等待用户决定。

## 转向判断

不要把“保持主线”理解为永不转向。出现 `PIVOT_CANDIDATE` 时比较：

- 原路线尚缺的决定性证据和获取成本；
- 新路线可形成的候选贡献及其证据基础；
- 已有数据、代码和实验能够复用的程度；
- 一项能够区分“继续”与“转向”的最小实验。

用户决定转向后再更新研究罗盘；决定前保留原目标，不把候选方向写成既定目标。

## 创新候选

阶段结束、出现跨样本稳定的新现象或得到有信息量的负结果时，从以下角度按需扫描，不要求每类都产生候选：

- 机制或理论解释；
- 模型、算法或处理链；
- 实验设计、验证方法或评价体系；
- 适用边界、鲁棒性规律或反例；
- 可复用的系统或工程能力。

每项活跃候选最多记录以下字段：

| 字段 | 内容 |
| --- | --- |
| 潜在贡献 | 一句话说明可能新增了什么认识或能力。 |
| 当前证据 | 直接支持它的实验、数据或分析链接。 |
| 关键缺口 | 哪个缺失证据会阻止形成可靠主张。 |
| 区别对象 | 需要与哪项 baseline、常规解释或相关工作比较。 |
| 决定性验证 | 最小且最有区分度的下一项检查。 |
| 状态 | `CANDIDATE`、`TESTING`、`SUPPORTED`、`REJECTED` 或 `PARKED`。 |

本项目中的新现象不自动等于学术新颖性。没有充分文献对照时使用“创新候选”或“潜力点”；只有证据与相关工作比较均支持时，才形成论文级创新主张。

## 提醒规则

在以下事件出现时及时提醒：核心假设被关键证据削弱；连续工作没有降低关键不确定性；当前任务与目标成果联系不清；论文主张超过证据；出现稳定但未解释的改善；负结果揭示新的适用边界；阶段目标已完成但下一决策尚未明确。

提醒采用紧凑格式：

```text
方向状态：ALIGNED / SUPPORTING / EXPLORATORY / DRIFT_RISK / PIVOT_CANDIDATE
依据：与核心目标相关的最小证据
建议：下一项决定性检查，或确实需要用户决定的事项
```

同一证据和建议不重复提醒。未解决事项在 `PROJECT.md` 或等价入口只保留一条；解决后删除或移入相关实验记录。除科研有效性硬否决或重大范围决策外，提醒不构成默认等待点。

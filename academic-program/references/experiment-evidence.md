# 实验与绘图规则

规划、执行、总结科研实验、撰写结果或科研绘图时按需使用；普通代码解释不创建实验记录。

## 实验设计

运行前确定假设、输入数据及版本、方法与 baseline、参数、指标、成功标准和停止条件。按研究问题选择消融、负对照或鲁棒性检查，不机械要求所有类型。

涉及标签、真值、参考几何、人工标注、仿真假设或外部元数据时，记录来源、独立性和局限。训练/验证/测试划分匹配科学主张；相关样本按场景、受试者、设备、地点或时间分组，防止泄漏。

## 运行记录

复用已有 runner 和格式，不另建重复台账。没有约定时，在 outputs/runs/<run-id>/ 保存：

- run.json：唯一编号、开始/结束时间、输入标识及版本、命令与工作目录、参数或配置路径、随机种子（适用时）、环境、代码版本、输出位置。
- metrics.json：结构化指标及单位，不适用时省略。
- 完整日志及实际产物，包括失败证据。

创建目录必须拒绝覆盖，重跑使用新编号。Git commit 不能表示未提交修改；使用未提交变更时保留可恢复补丁及相关新增源码，或源码快照。非 Git 项目保存必要源码快照。大型数据复用版本标识或校验清单，不为每次任务重新扫描全部数据。

执行与验证状态分开记录，例如 execution_status: completed 与 validation_status: failed 可以同时出现。验证未运行记为 not_run。中断且未收尾的运行保留未完成状态，不猜测结果。

## 单份全过程记录与收尾清理

每个实验（包含其重跑和修正）维护一份稳定文件名的全过程文档，例如 docs/experiments/kr-baseline.md；已有记录则继续更新，不为每次运行、每轮对话分别新建总结。

该文档按阶段记录目的与方案、输入和代码/配置入口、验收门槛、运行编号与命令、主要结果、失败及修正、最终结论与边界、产物位置和清理情况。多次运行用紧凑表格追踪，链接必要机器记录，不复制整份日志或参数表。实验有实质性进展时及时更新，避免中断后只剩终端历史。

实验收尾默认检查并清理本任务产生的冗余中间文件，包括已废弃临时脚本、重复预览图、可重建缓存和不再需要的中间产物。删除前确认：属于本实验、位于已解析核实的工作区内、可重建或已有可靠最终替代、未被后续步骤及复现链引用。记录清理类别、路径和理由，不另建清理报告。

保留原始输入、最终 PNG、必要数值结果、配置/源码版本以及支撑结论或失败诊断的最小充分证据。失败实验可以清理无证据价值的冗余副本，但保留失败原因、相关指标和必要诊断日志。无法确定用途或属于其他任务的文件不删除，在全过程文档说明。不要为保持目录空旷牺牲可复现性。

## 解释与论文证据

在 docs/experiments/ 或已有文档中记录目的、设置入口、发现、失败或局限和下一步。参数、指标和环境链接到运行记录，避免重复维护；引用关键指标时标明来源。

每项论文主张追溯到实验记录、代码/配置、指标及图表：

- 已证实结果：直接证据支持，注明数据和验证范围。
- 合理解释：不是唯一被证明的机制，说明可验证或推翻它的证据。
- 待验证或未来工作：不写成已经完成的成果。

没有实验设计直接支持，不声称盲估计、独立真值、泛化、因果、端到端或完全自动。不删除或隐藏失败结果，不改阈值制造通过。

## 科研绘图默认值

用户明确指定要求时以用户要求为准，否则：

- 图内标题、坐标轴、图例、色条、标注和面板说明使用简洁英文，单位明确，避免长段解释；详细讨论写入正文或 caption。
- 所有图中文字默认 Times New Roman（包括坐标刻度、图例和色条）；数学符号采用兼容字体设置，避免混入明显不一致的默认字体。
- 放大字体以保证最终使用尺寸下清楚可读；可从轴标签 16–18 pt、刻度/图例 14–16 pt 起步，按画布和最终尺寸调整，不机械固定字号。
- 通过增大画布、边距、面板间距、调整图例或标注位置解决重叠，不以缩成难读的小字作为默认办法。
- 图像仅导出 PNG，不额外生成 PDF、SVG、EPS、JPEG 或绘图工程格式副本；这不禁止保存复现实验所需源码、配置和数值数据，也不改变用户另外要求的论文文档格式。
- PNG 默认可采用 300 dpi，并按实际尺寸检查。保留来源运行、生成命令及数据/配置，保证可复现。
- 检查字体可用性；缺失时说明，不静默换字体后声称满足要求。
- 导出后实际查看 PNG，检查文字与曲线、图例、相邻面板不重叠，标签无裁切，字体和单位一致。保存成功不等于视觉验收通过。

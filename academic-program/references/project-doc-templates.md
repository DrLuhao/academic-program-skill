# 项目文档模板

仅在初始化、补充持久约定或明确迁移时使用。按实际信息填写，未知事项标明待确认，不创建空目录或无用章节。文件名使用英文，正文随项目语言。

## 选择数量

- 一次性咨询或分析：不创建管理文档。
- 小型持续项目：仅 AGENTS.md，可附几行当前工作。
- 持续科研项目：AGENTS.md + PROJECT.md。
- 已有等价入口：继续使用，避免重复；多研究线共享稳定约束，各线按需维护状态，不预先批量创建。

## AGENTS.md：稳定约定

合并到已有文件，不覆盖已有指令。只写项目特有、会改变操作决策的信息，不复制通用 skill 规则。可采用以下大纲：

- 关键入口：实际代码入口、运行配置、研究状态入口、实验证据入口；不要求每次全文读取状态文档。
- 文件与数据：实际目录职责、外部数据配置方式、只读范围、临时产物与正式结果位置。
- 执行与验证：工作目录、实际运行命令、验证命令及科学有效性检查。
- 特有约束：单位、坐标、数据格式和禁止改动项等。

## PROJECT.md：当前研究状态

仅在状态改变时更新；历史细节移入专题文档，保留链接，不追加对话流水账。可采用以下大纲；没有实际内容的可选项不创建：

- 研究罗盘：核心科学问题、目标成果或目标主张、当前核心假设、不可偏离的范围边界、下一项决定性验证。
- 当前阶段与方向：已完成工作、当前验证事项、方向状态（`ALIGNED`、`SUPPORTING`、`EXPLORATORY`、`DRIFT_RISK` 或 `PIVOT_CANDIDATE`）及相关证据链接。
- 近期任务：具体动作、完成标准、相关实验方案。
- 阻塞与待确认：缺失信息或失败门槛，没有则省略。
- 主张与证据入口：主张、状态（已证实/合理解释/待验证/未来工作）、适用边界和记录链接。
- 活跃创新候选：潜在贡献、已有证据、关键缺口、区别对象、下一项决定性验证和状态；没有可靠候选时省略。
- 未解决提醒：只保留仍会影响方向、有效性或主张的事项；已解决后删除或移入相关实验记录。

主张较多时完整映射维护在一个专题证据文件，状态页只保留相关摘要和链接。

## 旧三文档兼容与迁移

日常任务复用旧入口：文件定位查看 project-files.md，项目规则查看 project-rules.md，研究规划查看 project-plan.md。不跳过其中实际适用的指令。

用户要求迁移时：

1. 检查旧文档、现有 AGENTS.md 及指向它们的引用。
2. 将关键目录入口和稳定规则合并到 AGENTS.md；目标、当前任务和证据入口放入 PROJECT.md。
3. 历史实验和旧计划归入已有专题记录或 docs/archive/，核对科学约束与证据未丢失。
4. 更新项目内引用；需兼容的旧入口暂留简短转向说明，避免两套正文。删除旧文件仅在授权范围内执行。
5. 验证链接存在、关键命令和约束保留、原有代码与数据路径未被擅自改变。
